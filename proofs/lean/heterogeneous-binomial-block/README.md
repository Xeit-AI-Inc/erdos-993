# Zero-extended binomial-block signs

Byte-identical governed Lean source for the coefficient conjunction covering rise, fall and strict rise of the specified binomial blocks, including integer leading/trailing zero extension and both parities. The theorem concerns coefficients only; no graph or aggregate theorem is claimed.

Lean 4.32.2; Mathlib `905b95818eb32af7874a58b427f50c1711a5e96c`. With pinned dependencies available, run `lake build` then `lake env lean LeanProof/Main.lean`. Dependencies and build caches are not bundled. The publication-safe receipt summary retains the original canonical receipt hashes. All failed proof attempts and metadata repair history remain preserved internally.
