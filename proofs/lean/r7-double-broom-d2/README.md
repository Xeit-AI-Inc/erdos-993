# r7 Double-Broom D2 Package

Candidate `C4-F3-06` proves `C4F306.C4_F3_06`: every labelled double-broom
`D_(2,m)` for `m >= 0` is free of the exact first-recovery predicate at every
natural rank pair.

Build with `lake build C4F306`, then run `lake env lean KernelCheck.lean` and
`lake env lean AxiomCheck.lean`.

This is a proper-family exclusion, not a result for arbitrary double-brooms,
trees, forests, transfer, or Erdős #993.
