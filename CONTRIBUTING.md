# Contributing

Research questions, reproducibility reports, literature pointers, and exact
counterexamples are welcome as GitHub issues.

The repository is not yet accepting external pull requests. Contributor and
licensing terms will be established before outside code or proof text is
merged.

When opening an issue:

1. State the exact theorem, computation, or source claim.
2. Separate proof from experiment and conjecture.
3. Include replayable code and exact versions for computational claims.
4. Supply canonical graph data and independently computed coefficients for any
   proposed counterexample.
5. Identify every assumption, boundary case, and known failure mode.

Please do not submit private data, proprietary source text, credentials, or
unlicensed copyrighted material.
