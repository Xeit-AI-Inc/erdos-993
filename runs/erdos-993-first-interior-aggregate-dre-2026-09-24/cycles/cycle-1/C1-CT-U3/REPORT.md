## Direct proof check

Use the frozen definitions in `SEMANTIC-CONTRACT.md` and `SOLUTION-CONTRACT.md`. For an original leaf `v` with support `s`, let `W_v=N_T(s)\setminus{v}`. The vertex set of `R_v=T-N_T[s]` is exactly the vertex set of `H_v=T-{v,s}` minus `W_v`. Both are induced graphs. Thus every independent set of `H_v` is either disjoint from `W_v` and an independent set of `R_v`, or meets `W_v`; these classes are disjoint. If `C_k(v)` denotes the number in the latter class at size `k`, then `C_k(v)=i_k(H_v)-i_k(R_v)` exactly, including zero extensions. Consequently `Delta_(p-1)(H_v)-Delta_(p-1)(R_v)=C_p(v)-C_(p-1)(v)`. Summing with the original favorable leaf as a tag proves `S(T,p)=A_p(T,p)-A_(p-1)(T,p)` and preserves multiplicity when leaves share a support.

For the selector, partition independent sets of `T-v` according to whether they contain `s`: `I_(T-v)(z)=I_(H_v)(z)+z I_(R_v)(z)`. Taking coefficients gives `Delta_p(T-v)=Delta_p(H_v)+Delta_(p-1)(R_v)`. The strict selector is therefore expressed correctly. It controls a different coefficient combination from `C_p(v)-C_(p-1)(v)`; these identities alone do not prove the aggregate sign. An additional tree-wide argument establishing `A_p<=A_(p-1)` on eligible rows, or an eligible positive complete sum, is still required. This conclusion does not claim that the selector and graph constraints can never imply the sign by a further argument.
