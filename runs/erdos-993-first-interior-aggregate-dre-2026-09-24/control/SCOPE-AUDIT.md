- `F_p(T)` contains **original** leaves only, selected by `Δ_p(T−v)<0`. Each original leaf contributes one summand, including when several leaves share a support. An empty favorable set contributes zero. `s_v` is its unique neighbor in `T`; `H_v=T−{v,s_v}` and `R_v=T−N_T[s_v]` are evaluated using the **original graph's** support and closed neighborhood. In the r26 Lean convention, `H_v` and `R_v` name deletion sets, and the count is over independent sets avoiding those sets on the original vertex type; this is the same ordinary-graph deletion meaning.
