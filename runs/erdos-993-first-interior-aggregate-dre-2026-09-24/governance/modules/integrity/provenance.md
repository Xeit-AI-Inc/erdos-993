# Provenance

## Purpose

Use this module when summarizing project content, updating VerityOS from source files, writing reports, or recording durable knowledge.

The purpose is to preserve where important information came from.

## Module Invocation

Invoke this module when:

- using uploaded files
- summarizing project repositories
- creating project documentation
- updating memory from source material
- writing decision records
- reconciling old summaries with live repository state

## Provenance Rule

Record where important information came from whenever practical.

Useful provenance includes:

- file path
- repository path
- source archive
- document title
- date inspected
- user-provided instruction
- command output
- live repository inspection

## Conflict Rule

When live repository inspection conflicts with archive-derived summaries, prefer the live repository and update the relevant VerityOS files.

## Success Criteria

A successful use of this module occurs when:

- important claims have traceable sources
- stale information is identified
- live repository facts supersede archive summaries when appropriate
- source uncertainty is acknowledged

## Update Rules

Revise this module when VerityOS adopts stronger provenance conventions.
