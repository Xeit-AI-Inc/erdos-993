# Cycle 2 review protocol
Critics independently assess only their assigned origin return and its evidence, using the pinned case. Common supporting authority is additionally the original neutral handoff, semantic/solution contracts and historical source files listed in packets/C2-T1-v2.json (the common source list is identical for all nine searchers). This does not admit any sibling search or critique return. Review every incoming claim; reproduce meaningful calculations by copying scripts into your OWN assigned scratch, never execute source evidence in place. Assess novelty, applicability and exact scopes; no simulated or invented build/test results. A T critic attempts constructive repair while auditing; F actively falsifies; U probes ambiguity and missing hypotheses. All three must reject false arguments.
Neutral origin adjudicators see their three origin search returns plus six cross-orientation critiques, common semantic authority and the historical sources if needed. Give a precise per-claim retained/retained_narrowed/rejected/unresolved disposition, with reasons reconciling objections. Include every distinct incoming claim ID exactly once in covered_claim_ids and one disposition claim entry per ID. Do not count agreement as evidence. Any new lemma must have its own ID, exact proof and clearly proposed status.
Synthesis has a stricter source boundary: ONLY the three sealed adjudication returns/reports/evidence named in its case, SEMANTIC-CONTRACT.md, SOLUTION-CONTRACT.md, WORKER-PROTOCOL.md and this operational paragraph. It must not read the common mathematical packet, raw routes, critiques, historical snapshots or controller mathematical notes. Adjudicators must make their admitted mathematics self-contained. Synthesis covers every incoming adjudicated claim, identifies common dependencies and unresolved contradictions, and selects an exact centrally relevant Lean candidate only if its proof and dependency DAG are closed. An OPEN primary claim stays OPEN. Recommend next-cycle questions from adjudicated evidence; do not invent status awards.
All roles use GPT-6 Sol high. Physical outputs ONLY assigned absolute scratch directory; RETURN paths should name eventual cycles/cycle-2/WORKER-ID files. Put source citations in report prose; RETURN evidence_paths should name the role's own output artifacts so a downstream packet can pin them unambiguously. No Lean builds this stage. Stop owned jobs before final write. Worker claims are proposed_only and do not update the canonical registry.
