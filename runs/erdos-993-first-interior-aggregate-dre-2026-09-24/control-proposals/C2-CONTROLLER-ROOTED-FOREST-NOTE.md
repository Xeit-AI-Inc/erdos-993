# Controller frontier note — unawarded, for final review

For an actual ordinary tree and original leaf v with support s, H=T-{v,s} is a forest. The set W=N_T(s)-{v} meets every component of H in exactly one vertex: connectedness gives an attachment to s, and two such attachments in one component would create a cycle. Thus the relevant tagged pair (H,W) is a forest with one marked root per component, more structured than the arbitrary bipartite graph and arbitrary W used by the core lemma.

This observation is a possible source of a stronger estimate, not a proof that the all-rank pointwise sign survives. The known T22 off-target positive local term at p=34 already prevents promoting high-tail pointwise monotonicity to all eligible ranks. Aggregate cancellation remains necessary in that lower region.

A useful stress example for a rooted refinement is a matching with a components and one designated endpoint per edge. The independent k-sets meeting the designated roots number q_k=binomial(a,k)*(2^k-1). This tests a proposed root-sensitive inequality exactly and shows that one cannot assume arbitrary extra slack merely because every component carries a root. This is an informal controller derivation, not an independently audited or registered new claim.

The primary closure, if its fidelity gate passes, should redirect the aggregate search toward eligible ranks below 3*p>=2*alpha(T)+1, keeping original favorable selectors and all leaf tags. A program claiming to close the entire all-rank target must additionally account for every small-rank endpoint and the independent ordinary-to-governed-model bridge.
