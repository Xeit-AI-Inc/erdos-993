### Two candidate claims proposed by this route (STATED; not registered — Ruling 18 freezes the registry until the Cycle 2 second-reads packet seals)

**Candidate 1 — `E993-R30-EQUITABLE-PARTITION-FLOW-LIFT`.**
> Let `S`, `T` be finite sets, `R ⊆ S × T`, `supply : S → ℕ`, `capacity : T → ℕ`. Let `π_S`, `π_T` be partitions of `S`, `T` into classes on which `supply`, `capacity` are constant, such that for every class pair `(C_s, C_t)` every `u ∈ C_s` has exactly `r(C_s, C_t)` neighbours in `C_t` and every `t ∈ C_t` has exactly `r'(C_s, C_t)` neighbours in `C_s` (an *equitable partition* of the bipartite relation; `|C_s|·r(C_s,C_t) = |C_t|·r'(C_s,C_t)` for every pair with `r(C_s,C_t)>0`). Define the quotient network with one node per class, arc `(C_s,C_t)` present iff `r(C_s,C_t)>0`. Then: **an integral flow `f : S×T → ℕ` exists with `f(u,t)>0 ⇒ (u,t)∈R`, `Σ_t f(u,t) = supply(u)` for all `u`, `Σ_u f(u,t) ≤ capacity(t)` for all `t`, if and only if an integral quotient flow `F(C_s,C_t)` exists with `F(C_s,C_t)>0 ⇒ r(C_s,C_t)>0`, `Σ_{C_t} F(C_s,C_t) = |C_s|·supply(C_s)` for all `C_s`, `Σ_{C_s} F(C_s,C_t) ≤ |C_t|·capacity(C_t)` for all `C_t`.**
>
> Proof. (⇒) Given `f`, set `F(C_s,C_t) := Σ_{u∈C_s, t∈C_t} f(u,t)`; summing the row/column constraints of `f` over each class recovers exactly the quotient constraints (no equitability needed for this direction, only constancy of `supply`/`capacity` on classes). (⇐) Given `F`, for every class pair with `r := r(C_s,C_t) > 0` set `f(u,t) := F(C_s,C_t) / (|C_s|·r)` for every `(u,t) ∈ R` with `u∈C_s,t∈C_t` — a single number, the **same** for every edge between the two classes. Using `|C_s|·r = |C_t|·r'`: for `u ∈ C_s`, `Σ_t f(u,t) = Σ_{C_t} r(C_s,C_t) · F(C_s,C_t)/(|C_s|·r(C_s,C_t)) = Σ_{C_t} F(C_s,C_t)/|C_s| = supply(C_s) = supply(u)` (exact equality, using the quotient's own supply constraint); for `t ∈ C_t`, `Σ_u f(u,t) = Σ_{C_s} r'(C_s,C_t)·F(C_s,C_t)/(|C_s|·r(C_s,C_t)) = Σ_{C_s} F(C_s,C_t)/|C_t| ≤ capacity(C_t) = capacity(t)`. This `f` is a nonnegative **rational** point of the transportation polytope `P = {f ≥ 0 : f=0 off R, row sums = supply exactly, column sums ≤ capacity}`, so `P` is nonempty; `P` is also bounded (finite `S`, `T`). The constraint matrix of `P` is (up to the standard slack-variable trick on the capacity inequalities) the vertex–edge incidence matrix of the bipartite graph `(S, T, R)`, which is totally unimodular (a classical fact: incidence matrices of bipartite graphs are TU, e.g. via the standard interlacing/Ghouila-Houri criterion, since a bipartite graph has no odd cycles). A nonempty bounded polytope with a TU constraint matrix and integer right-hand side has an **integral vertex**; take that vertex as `f`. ∎
>
> This is an *iff*, sharper than what part (a) of the obligation asked for (which asked only for the (⇐) direction). It requires **no finite group anywhere**: only the two local-regularity numbers `r(C_s,C_t)`, `r'(C_s,C_t)` per class pair. It is therefore satisfied by partitions that are **not** unions of automorphism orbits of any group acting on the ambient structure, whenever such orbits fail to exist (e.g. because the ambient object has no automorphism relating two pieces that nonetheless look identical *to the relation R, supply and capacity alone*). Concretely exhibited in `scratchpad/c2-U2-replay/lift_toy.py`: the disjoint union of a 4-cycle and a 6-cycle (bipartite; every vertex degree 2) has **4** automorphism orbits (computed by brute-force search over all side-respecting bijections preserving the edge set: `{a1,a2}`, `{b1,b2}`, `{c1,c2,c3}`, `{d1,d2,d3}}`) because no automorphism can map the 4-cycle's component onto the 6-cycle's (different orders), yet the **2**-class partition `{all sources}, {all targets}` is equitable (`r = r' = 2` uniformly) and strictly coarser. The closed-form fractional lift gives `f ≡ 1/2` on every edge (exact `Fraction`, verified to satisfy every constraint with equality on the source side and equality on the target side here), and an independent exhaustive search finds the predicted integral lift (a perfect matching, e.g. `a1↦b1, a2↦b2, c1↦d1, c2↦d2, c3↦d3`).
>
> Proposed grade: `proved_informal` (a complete, self-contained elementary proof from total unimodularity of bipartite incidence matrices, a standard cited fact; no `sorry`, no computation-only step; needs an isolated second read before registration per Ruling 18).

**Candidate 2 — `E993-R30-CB-TRANSPORT-EQUITABLE-PARTITION-RIGIDITY`.**
> On the literal CB(d, m) two-for-one transport relation (SEMANTIC-CONTRACT §1.2 (D)∪(S), with `F` the full leaf set), the partition of independent sets by the **aggregate** invariant "(number of chokes present, total supports selected among absent chokes, total leaves selected among absent chokes)" — i.e. any coarsening that keeps only the *marginal totals* `(U, ΣA, ΣB)` across the `m` arms and forgets the *per-arm* split of `(a_i, b_i)` — is **not** an equitable partition of this relation in general: two independent sets can share the same aggregate invariant while sending their two-for-one switch arcs to different numbers of resulting-weight classes.
>
> Proof/witness (exact, `scratchpad/c2-U2-replay/coarsening_impossibility.py`): on CB(5, 2), configuration `A` (arm 1: `a=2,b=3`; arm 2: `a=2,b=1`) and configuration `B` (arm 1: `a=2,b=2`; arm 2: `a=2,b=2`) are both independent 8-sets with root/`s`/`v` and both chokes absent, hence both have active weight `0` and share the aggregate invariant `(ΣA, ΣB) = (4, 4)`. Both have exactly two vertices eligible for a two-for-one choke-insertion switch (`a_i = 2` in each arm, root absent). Config `A`'s two switch targets have weight-shift multiset `{1, 3}` (two distinct outcomes, one arc each); config `B`'s have `{2, 2}` (one outcome, two arcs). A partition that could not distinguish `A` from `B` would have to assign the same arc-count vector to both, which is false here (`{1:1, 3:1}` ≠ `{2:2}`). Hence any equitable partition of this relation must resolve at least the per-arm `(a_i, b_i)` (equivalently, at least the full `S_d ≀ S_m` branch-type histogram), confirming that "54 branch types" (`(d+1) + (d+1)(d+2)/2 = (d+1)(d+4)/2 = 54` at `d = 8`) is not merely a computational inconvenience but the genuine minimal granularity for this specific style of aggregate coarsening.
>
> Scope note (kept precise, not overclaimed): this rules out *this* natural style of coarsening (marginal totals only); it is **not** a proof that no equitable partition whatsoever, of any other design, could be coarser than the full orbit histogram for this relation. Proposed grade: `bounded_computation` (an exact witness, not a universal impossibility theorem over all conceivable partitions).
