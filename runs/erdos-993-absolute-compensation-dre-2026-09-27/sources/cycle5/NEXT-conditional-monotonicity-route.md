# Private conditional-monotonicity route, not a current C4 input

A possible interpretation of the existing OPEN ordinary P/deletion LR claim is monotonic leaf occupancy under the uniform independent set conditioned on total size. The rooted main polynomial C=G product B_r factors into independent block count distributions. For an r-star block the expected number of selected tips given local rank t is0 at0, r/(r+1) at1, and t for2<=t<=r; for a specified tip divide by r. This function is nondecreasing. The local count coefficients B_r are ordinary log-concave forr2/3/4. Thus a correctly stated discrete conditional-monotonicity theorem could explain the already plausible main-product LR behavior. This is a research interpretation, not an imported theorem or formal proof.

The full parent P=C+d, d=zL^(N+1), is a mixture over a root state, so the independent-block argument does not apply without another bridge. In particular it is false that the root-state mixture weight always increases with rank. Exact private controls NEXT-root-mixture-minors.py/.json show, at allr2m10,N20,n33,k4, d4=1330,d5=5985,C4=27315,C5=125586 and d5*C4-d4*C5=-3549105. Consequently d/(C+d) decreases from4to5. This is a shortcut obstruction on rising ranks, not a selected-payment or eligible-rank counterexample. No minimum-order claim or registered award is made. A useful conditional coupling must handle this mixing defect rather than assume it away.

Literature lead: Efron, Increasing Properties of Polya Frequency Functions (1965), Annals of Mathematical Statistics36,272–279; discrete version must be checked in the primary theorem/remark before use. Newer primary work [Saumard and Wellner, arXiv1707.04472](https://arxiv.org/abs/1707.04472) extends monotonicity beyond independent measures in a continuous two-dimensional setting; it is not by itself a discrete tree theorem. Any application must state the exact hypotheses and prove them for the finite coefficient law.
