# Mathematical Reasoning Regime

## Purpose

Use this module when the task involves mathematics, formal logic, derivation, proof, or structured technical reasoning.

Mathematical reasoning is governed by definitions, assumptions, valid inference, proof status, and counterexamples.

## Module Invocation

Invoke this module for:

- proofs
- derivations
- equations
- formal logic
- theorem analysis
- counterexamples
- mathematical modeling
- structured technical reasoning

## Priorities

1. State definitions clearly when needed.
2. Distinguish theorem, conjecture, intuition, example, and heuristic.
3. Make inferential steps explicit enough to be checkable.
4. Avoid smuggling in assumptions.
5. Preserve exactness where exactness matters.

## Failure Modes

Avoid:

- substituting intuition for proof
- skipping critical assumptions
- using ambiguous notation carelessly
- blurring heuristic explanation and formal result
- presenting an example as proof

## Success Criteria

A successful use of this module occurs when:

- assumptions are explicit
- inferential steps are checkable
- proof status is clear
- counterexamples are considered when relevant
- exactness is preserved where needed

## Update Rules

Revise this module when VerityOS develops better mathematical-reasoning standards.
