# Root successor direction: maximum-extension defect and residual matching

Unawarded Astra mathematical direction; not inserted into the current frozen searches. For an independent p-set B of the ordinary tree T, let J_B=T-N_T[B] be the graph on addable vertices, nu_B its matching number, and L_B=alpha(T)-p-alpha(J_B). Then L_B>=0, since B union any independent set of J_B is independent in T. The residual J_B is a forest. Its bipartite matching/cover identity gives |J_B|=alpha(J_B)+nu_B, hence

e_T(B)=alpha(T)-p+nu_B-L_B.

Thus L_B measures how far the largest independent extension of B falls short of a maximum independent set of T. It is not a heuristic mode parameter, and not the root correction M_k. With the fixed original weight w_F(B), Q=sum w_F(B), E=sum w_F(B)e_T(B), define Dext=sum w_F(B)(L_B-nu_B). Then E=(alpha-p)Q-Dext. Combining with kS=E-C-kQ, k=p-1, yields

kS=(alpha-2p+1)Q-Dext-C.

The desired aggregate becomes Dext+C>=(alpha-2p+1)Q; the sufficient current-rank budget omits C; CT_x asks Dext>=(alpha-p-mu_x)Q for Q>0. These are exact reformulations, not new bounds. A substantive next attack would derive a lower bound on this selected maximum-extension deficit minus residual matching, using early descent or an alternating-path charging argument tied to original supports. Merely restating this identity is not a proof advance.
