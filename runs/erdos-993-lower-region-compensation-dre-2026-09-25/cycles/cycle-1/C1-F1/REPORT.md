# C1-F1 — adversarial multi-hub exact search

## Result

A seeded, finite exact search found no eligible positive aggregate. It evaluated 30 generated root multi-hub trees at their complete eligible rank ranges: 14 recipes with 91 vertices, 14 with 243 vertices, and the two unperturbed anchors. Across 582 tree/rank rows, every computed full selected sum satisfied S(T,p) <= 0. This is a bounded observation. It neither proves the registered universal assertion nor refutes it.

## Graph family, generation boundary, and replay

The tree has root 0; m hub vertices adjacent to the root, with d_i in {1,...,6} distinct pendant leaves at hub i; r in {1,2,3,4} subdivided root arms, each root–support–leaf; and c in {0,1,2,3} direct root leaves. Its order is 1+m+sum_i d_i+2r+c. Thus every graph is connected and acyclic by construction. The two anchor recipes are m=22, all d_i=3, r=1,c=0 (order 91), and m=60, all d_i=3, r=1,c=0 (order 243).

The deterministic Python PRNG seed is 99320260925. For each target order 91 and 243, generation made 14 recipes: choose m uniformly from target hub count minus 2 through plus 2, choose r,c from the ranges above, distribute the required sum d_i evenly over m hubs, then make 10–80 random legal unit transfers between two hub leaf counts, preserving the required order and 1 <= d_i <= 6, and shuffle the list. The search therefore fixes each target order but varies hub count, pendant-leaf profile, number of subdivided arms, and direct root leaves. It is a sample of this family, not its exhaustive enumeration. Candidate recipes are not deduplicated.

The script imports the pinned inputs/ordinary_tree_checked.py. Its exact forest independence-polynomial DP supplies a=alpha(T), each original-tree leaf-deletion polynomial used for the strict selector, and both deleted-graph polynomials in each summand. It checks x(T) through rank a; for each p=x+2,...,floor(2a/3), which is equivalent for integer p to the strict guard 3p<2a+1, it visits each original leaf ID separately, tests Delta_p(T-v)<0, and adds

    Delta_(p-1)(T-{v,s_v}) - Delta_(p-1)(T-N_T[s_v]).

The stored output contains all 582 exact aggregate integers and favorable-leaf counts, plus recipes, a, x, p, and the tested-rank list. Repeated supports remain separate leaves in the implementation. The count 582 comprises 137 rows at order 91 and 445 at order 243. Tested p-ranges across the samples are 34–45 and 89–122, respectively.
