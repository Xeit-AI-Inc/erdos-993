## Audit

The definitions are implemented as stated: `F_r` has coefficients `binom(r-1,j+1)` for `0 <= j <= r-2`, and `B_s` has binomial coefficients with one added to its degree-one coefficient. Exact integer convolution tests each `(r,s,q)` with `2 <= r,s <= 20` and `1 <= q <= 4`, for 361 pairs and 1,444 products.

For a positive coefficient sequence `a_0,...,a_n`, finite-order ULC of order `d >= n` is log-concavity of `a_j/binom(d,j)`. Clearing the positive binomial denominators gives `(d-j) A_j >= R_j`, where `A_j = j a_j^2 - (j+1)a_(j-1)a_(j+1)` and `R_j=(j+1)a_(j-1)a_(j+1)>0`. Thus any finite order requires `A_j>0` at every interior index; if all are positive, the least valid order is `max(n, max_j(j+ceil(R_j/A_j)))`. The copied replay checks the resulting inequalities exactly at each claimed order. This matches the lead's criterion.
