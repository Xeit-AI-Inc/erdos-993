# Fresh independent review of the four r27 packages and root correction

## Findings that affect the next mathematical step

**1. The optimized correction is sound but does not supply a marked-family bound (high relevance; unresolved transfer).** The registered term is
\(M_k(G)=\sum_{C\in\pi_0(G)}\max_{w\in C}c_w(k)\), where \(c_w(k)\) counts *all* independent \(k\)-sets of the whole forest containing \(w\). The root incidence in the compiled `C1-LA1` lemma counts a set once for **each** chosen component root it contains. The compiled statement is for the `rootRep` rooting, `D_k+2|rootPairs|≤2k i_k` (`sources/public/proofs/lean/r27-c1-la1-forest-degree-extension/source/LeanProof/Main.lean:1006-1015`); the every-rooting and optimized-max presentation is registered at `proved_informal`, not as a separate formal award (`sources/verity/experiments/erdos-993-master-ledger-2026-09-04/CLAIM-IDENTITY.json:36991-36996`; `sources/verity/experiments/erdos-993-forest-degree-extension-dre-2026-09-24/second-reads/SR-RC/SECOND-READ.md:179-185`). Maximizing each component root separately gives the claimed inequality because the `D_k` and `i_k` terms do not change with the rooting; conversely the max inequality implies each fixed-root version. This is a valid deduction from the informal every-rooting proof, not a new Lean endpoint.

For an original leaf \(v\) with support \(s\), the interior target uses \(H_v=T-\{v,s\}\), \(W_v=N_T(s)\setminus\{v\}\), \(R_v=H_v-W_v\), and \(q_v(j)=i_j(H_v)-i_j(R_v)\). Its term is \(q_v(p)-q_v(p-1)\), selected only when \(\Delta_p(T-v)<0\), with every original leaf retained as its own tag. Each component of \(H_v\) has exactly one vertex of \(W_v\); this makes \(W_v\) a legitimate root selection. It does **not** turn `M_k(H_v)` into `q_v(k)`: root incidences sum with multiplicity, whereas `q_v(k)` counts a set meeting at least one root once. Thus \(q_v(k)\le\sum_{w\in W_v}c_w(k)\le M_k(H_v)\), with both inequalities potentially strict. The global root inequality has the wrong control to bound \(q_v(k+1)\) from above or sign its forward difference. The graph-general extension double count and lower bound likewise give a *lower* bound for the next total coefficient, not an upper bound on the marked shadow (`C1-LA2` contract `THEOREM-CONTRACT.md:12-26`; source `Main.lean:279-356`). An independent selected-sum compensation argument would have to preserve the fixed favorable selector and control the actual marked deficit across supports. The incidence-deficit identity in `work/erdos-993-first-interior-aggregate-dre-2026-09-24/FINAL-ANALYSIS.md:51-59` names such an obligation; the r27 results do not discharge it.

There is a small exact witness against restricting (RC) to marked sets. Take the tree with edges `01,12,23,14,45`, \(v=0,s=1\). Then \(H\) consists of edges `23` and `45`, and \(W=\{2,4\}\), one root per component. At ranks 1 and 2, \((i_k,D_k,M_k)=(4,4,2),(4,8,4)\), so optimized (RC) is **tight** at both ranks. Yet \(q_1=2,q_2=3\): the marked term at \(p=2\) is `+1`. Moreover \(T-v\) has \(i_2=6,i_3=1\), hence this original leaf is favorable at `p=2`. If one sums only over marked sets, the proposed RC expression already fails at rank 1: marked `D=2`, marked root incidences `=2`, marked count `=2`, giving `2+2·2=6>4=2·1·2`. At rank 2 it is `6+2·4=14>12`. The injection for all independent sets need not remain inside a root-meeting family. This tree has \(\alpha(T)=3\) and is **outside** the first-interior eligibility condition; it does not refute the verified interior theorem or an eligible all-rank aggregate. The finite calculation is reproducible in `review/scratch/check_transfer_example.py`.

**2. Corollary B's equality wording needs an endpoint guard (medium, registry-text correction).** The inequality `n D_k+2k i_k≤2k i_k n` is correct, including `n=0`. But the second read says equality holds “exactly for trees at k=1” (`SR-RC/SECOND-READ.md:190-192,363-364`), and the registry repeats that unqualified phrase (`CLAIM-IDENTITY.json:36991-36993`). At `k=0`, every forest has `D_0=0`, so both sides are zero; if `i_k=0`, both sides are again zero, including every out-of-support rank. The empty forest is another endpoint. The accompanying census claim of 987 tight rows evidently treats only positive supported ranks (`SR-RC/SECOND-READ.md:216-218`). Retain the inequality, and qualify any equality classification by the domain actually proved, e.g. `k≥1`, `i_k>0`, `n>0`; then verify whether equality is precisely trees at `k=1` within that domain before stating the iff. No compiled r27 award depends on the incorrect unqualified equality phrase.

**3. r28 closes off the proposed universal Hall/SDR rescue (high relevance).** The pinned r28 experiment and verification record report an order-22 tree with 19 independent 12-sets, root occupancy 18 and every leaf occupancy 17, refuting universal threshold slot-to-leaf dominance. The same sources record the verified restricted branch-tree-path theorem only (`sources/public/experiments/r28-degree-lemma-hall-sdr.md:15-32`; `sources/public/evidence/verification-2026-09-25-r28.md:24-38`). Thus a universal Hall step cannot be inserted between `M_k` and the marked aggregate. The restricted result is useful on its stated class but neither supplies a general marked-family bound nor changes the r27 forest degree lemma.
