# Public Experiments

This directory is reserved for bounded, replayable experiments that are safe
to publish. The internal research lineage contains a much larger operational
record, including raw model returns and quarantined failures, which is not
mirrored here.

Every published experiment must include its scope, source, replay command,
result, limitations, and hashes.

- [r6 NR-foundation summary](r6-nr-foundation.md): computation-grade terminal
  record; no public theorem package.
- [r7 joint-shadow-incidence summary](r7-joint-shadow-incidence.md): twelve
  reproducible auxiliary or conditional Lean packages and their boundaries.
- [r8 extension-profile and same-leaf summary](r8-extension-profile-same-leaf.md):
  terminal twelve-cycle record, eight verified auxiliary declarations, and the
  remaining strict-overlap and representation obligations.
